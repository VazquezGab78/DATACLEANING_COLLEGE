<div align="center"><h1>DATACLEANING_COLLEGE</h1></div>
<p>This Python soluction converts first and last names from uppercase to lowercase. It also allows names or surnames lacking accents to have them added.</p>
<hr>
<h2>Documentation</h2>
<ol>
  <li>(lista_unicos.csv) - Conjunto de nombres y apellidos unicos extraidos del dataset original para craar el dicicionario de correciones</li>
  <li>(dataset_normalizado.xlsx) - Dataset resultante (limpio) con las observaciones normalizadas (nombres y apellidos capitalizados y tildes correspondientes</li>
  <li>(dataset_original.xlsx) - Conjunto de datos originales con errores de Mayusculas y apellidos sin tildes</li>
  <li>(normalizacion_copia.py) - Código para limpieza y normalización del conjunto de datos</li>
  <li>(readme.txt) - Listas de librerias necesarias para el funcionamiento</li>
</ol>
